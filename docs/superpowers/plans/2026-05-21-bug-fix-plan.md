## 六、验收测试用例

### 项目管理测试
1. 创建项目 - 填写名称和描述，确认默认启用
2. 查看列表 - 确认状态显示正确
3. 禁用项目 - 点击禁用按钮，确认状态变更
4. 启用项目 - 点击启用按钮，确认状态变更

### APK上传测试
1. 上传APK文件 - 确认无500错误
2. 验证解析结果 - 确认包名和版本正确显示

### 设备管理测试
1. USB设备连接 - 点击连接，确认TCP/IP连接成功
2. 已连接设备再次点击 - 确认提示"已连接"
3. 离线设备连接 - 确认提示"离线"

### 任务管理测试
1. 打开创建弹窗 - 确认设备列表加载
2. 查看设备状态 - 确认在线/离线标签正确显示
3. 创建任务 - 选择设备后确认创建成功

### 关键字管理测试
1. 创建关键字 - 编写Python函数，确认保存成功
2. 语法错误测试 - 输入错误代码，确认提示正确
3. 编辑关键字 - 修改代码，确认更新成功

## 七、风险控制

| 风险 | 应对措施 |
|------|----------|
| 数据库字段修改失败 | 先备份数据库，在测试环境验证 |
| API端口不一致 | 检查vite.config.js和后端配置 |
| Python代码注入 | 严格语法验证，限制代码执行环境 |
| 测试设备不足 | 使用模拟器或已连接设备进行测试 |
