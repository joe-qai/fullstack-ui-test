## 六、验收测试用例

### 调试页面测试
1. 打开调试页面 - 确认无空白
2. 选择设备 - 确认 iframe 正确加载
3. 点击刷新 - 确认 iframe 重新加载
4. 点击新窗口打开 - 确认新标签页正常打开
5. 点击全屏 - 确认全屏功能正常

### 设备管理测试
1. 查看 TCP/IP 设备在线 - 确认显示"断开"按钮
2. 查看 TCP/IP 设备离线 - 确认显示"重连"按钮
3. 点击重连 - 确认重连功能正常
4. 点击断开 - 确认断开功能正常
5. USB设备 - 确认显示"连接"或"离线"

### 页面适配测试
1. 调整窗口大小 - 确认页面自适应
2. 小屏幕测试 - 确认内容可滚动
3. 测试滚动功能 - 确认能看到完整内容
4. 测试多个浏览器 - 确认兼容性

## 七、风险控制

| 风险 | 应对措施 |
|------|----------|
| iframe 跨域问题 | 提供新窗口打开作为备选方案 |
| 云端服务不可用 | 保留本地 uiautodev 支持 |
| 设备连接不稳定 | 提供清晰的错误提示和重试机制 |
| 样式兼容性问题 | 测试主流浏览器（Chrome、Firefox、Edge） |
