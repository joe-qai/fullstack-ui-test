> 日期：2026-05-23
> 目标：治理任务执行的可观测性和可取消性，统一前端 UI 风格，稳定 uiautodev 在线调试链路

## 1. 后端核心改造

### 1.1 脚本执行器重构 (`backend/executors/script_executor.py`)
- **`start()` / `wait()` 拆分**：`run_script()` 拆为 `start(script, device, project)` 和 `wait()` 两个方法
- **行级输出流**：`start()` 用 `select` + `PIPE` 逐行读取 stdout/stderr，实时推入 `self.logs`
- **取消支持**：`wait()` 接受 `cancel_check()` 回调函数，每行输出后检查，收到信号则 `process.terminate()`
- **`run_script()` 降级为代理**：直接调用 `start()` 后 `wait()`（无需取消的场景）
- **`run()` 统一入口**：Query `Script` 对象后委托给 `start()` + `wait()`

### 1.2 任务调度器增强 (`backend/core/task_dispatcher.py`)
- **进程追踪即时化**：`_execute_on_device` 在 `Popen()` 后立即记录到 `self.active_processes`
- **`cancel_task()` 硬终止**：调用 `process.terminate()` + `process.wait(timeout=5)` 兜底 `process.kill()`
- **状态传播**：取消后状态设为 `"cancelled"`，task 自身状态同步更新

### 1.3 在线调试服务管理 (`backend/core/uiautodev_manager.py`)
- **双启动策略**：优先 `uiauto.dev.exe server --no-browser`，失败回退 `python -m uiautodev`
- **停止全杀**：`stop()` 用 `taskkill /F /IM uiauto*` (Win) / `pkill -f uiauto` (Linux/Mac)
- **状态返回远程 URL**：`get_status()` 返回 `url=https://uiauto2.devsleep.com`
- **设备 URL 支持平台参数**：`get_device_url(serial, platform="android")` 返回 `https://uiauto2.devsleep.com/{platform}/{serial}`
- **服务不自启**：用户手动点击启动/停止/重启

### 2.3 任务管理增强 (`Tasks.vue`)
- **失败原因展示重构**：按 completed → running → cancelled → failed 分支，支持 `error_message`、失败步骤递归查找
- **颜色映射**：`getFailureColor()` 返回对应颜色

## 3. 在线调试优化 (`Debug.vue`)

### 3.1 工具栏精简
- **移除冗余按钮**：删除"加载主页"、"刷新"按钮
- **select 去 @change**：设备选择不自动加载，需点"加载设备"

### 3.2 iframe 双状态
- **服务未运行**：显示 `a-empty` 占位提示
- **服务运行中**：显示 iframe（带 loading spin）
- `currentIframeSrc` 直接替换为云 URL（`https://uiauto2.devsleep.com/`），绕过 Vite proxy
- `openInNewTab` 同样使用云 URL
- 启动/停止/重启均触发 `iframeKey++` 刷新容器
